# XClass

XClass는 속도보다 편리함이 중점인 OOP 프레임 워크입니다.

XClass는 **getter**, **setter**, **다중상속**을 지원합니다.

## 사용법

XClass는 먼저 이렇게 생성 할 수 있습니다.

local class = XClass.new(생성자(들), 기본값(메소드), 설정)

### 생성자(들)

생성자(들)에는 함수 또는 함수가 들어있는 테이블 또는 nil을 넣을 수 있습니다.

생성자(들)이 함수인 경우엔 { new = 함수 }와 같습니다.

생성자(들)이 nil인 경우엔 {}와 같습니다.

※참고: 생성자가 테이블인 경우 IgnoreCase, NumberKeysToString가 작동하지 않습니다.

### 기본값(메소드)

기본값(메소드)에는 nil또는 기본값 또는 메소드가 들어가있는 테이블을 넣을 수 있습니다.

기본값(메소드)가 테이블인 경우 메타메소드를 추가 할 수 있습니다.

기본값(메소드)에 메타메소드가 있을때 그의 자손에도 적용 가능합니다. (조상 클래스일수록 순서가 낮음)

**"__index"**

**"__newindex"**

**"__metatable"**

**해당 3가지 메타메소드는 사용 할 수 없습니다.**

### 설정

설정은 설정값들이 있는 테이블 또는 nil을 넣을 수 있습니다.

Extends: (XClass | { XClass })? 상속할 클래스. 다중 상속의 경우 인덱스가 낮을수록 순서가 높음.

Type: string? XClass.type, XClass.typeof라는 특수 내장 함수에 "userdata" 대신 사용할 문자열.

### getter, setter

XClass.getter(함수)또는 XClass.setter(함수)를 통해 원하는 함수를 getter 또는 setter로 지정 할 수 있습니다.

오브젝트에 getter 또는 setter인 값이 존재하는 경우 무시됩니다.

무조건 기본값(메소드)에 getter또는 setter이 있어야 작동합니다.

XClass.getter에 들어가는 함수는 다음과 같아야합니다.

(self) -> (값)

XClass.setter에 들어가는 함수는 다음과 같아야합니다.

(self, value) -> ()

### 상속

상속에서 조상의 생성자를 사용 해야할 경우엔 XClass.super(constructor (원하는 생성자), ...self를 포함한 매개변수들)로 사용 가능합니다.

## 편의기능

XClass엔 다른 클래스 프레임워크와 다르게 이 외에도 편의기능이 여러개 존재합니다.

### 생성자

※참고: 밑에 2개의 메소드는 생성자(들)이 테이블일 때 적용됩니다

※참고: 밑에 2개의 메소드는 해당 클래스의 생성자에만 적용됩니다.

__first: (self, ...매개변수들) -> () 어떤 생성자든 실행되기전 __first가 실행된후 실행됩니다

__final: (self, ...매개변수들) -> () 어떤 생성자든 실행후 __final이 실행됩니다


### 기본값

※참고: 밑에 3개의 메소드는 조상 클래스에도 호출됩니다. (조상 클래스일수록 순서가 낮음)

__get: (self, 인덱스, 현재 값, 현재 값이 완전히 비어있는지 여부) -> (수정할 값) 값을 받을 때 받을수 있는 값을 미리 확인 할 수 있습니다. 반환하는 값의 길이가 1 이상인 경우 첫번째 반환한 값으로 받을 값을 수정 할 수 있습니다. 

__set: (self, 인덱스, 현재 값) -> (수정할 값) 값을 설정 할 때 받을수 있는 값을 미리 확인 할 수 있습니다. 반환하는 값의 길이가 1 이상인 경우 첫번째 반환한 값으로 수정할 값을 수정 할 수 있습니다. setter에 경우 호출되지 않습니다.

__afterset: (self, 인덱스, 값) -> () 값 수정후 호출됩니다


### 설정

※참고: 밑에 2개의 설정은 상속된 클래스에도 적용됩니다. (조상 클래스일수록 순서가 낮음)

IgnoreCase: boolean (기본 ture) 대소문자 무시 (영어 전용)

NumberKeysToString: boolean (기본 false) 숫자 인덱스를 문자열로 바꿔서 사용
